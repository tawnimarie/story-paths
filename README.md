# ✦ story paths

*A wandering-library solo RPG for Discord, built for the Ink & Aether bookish community.*

Story Paths turns reading recommendations, reflections, and prompts into a small solo adventure through a magical library that never stays in one place.

Players wander through shifting locations, follow bookish story prompts, revisit familiar paths, discover alternate encounters, and build a persistent journal of their travels.

## ✦ how it works

Using `/storypath wander`, a player chooses a volume and receives a randomly generated path through a 6×6 story map.

The library remembers each player's journey. When a traveler returns to a path they've visited before, they can follow the original prompt again or let the library reveal an alternate path.

Players can also use `/storypath journal` to see their journey history, including paths wandered, unique places visited, alternate paths discovered, their most-visited location, and their latest path.

## ✦ features

- two 6×6 story-path volumes
- randomized coordinates and encounters
- persistent player journey history
- repeat-path detection
- alternate prompt system with no repeats until the full pool is explored
- one-hour wandering cooldown
- interactive Discord buttons
- personal journey journals
- persistent storage with Cloudflare D1

## ✦ built with

- Discord Interactions API
- Cloudflare Workers
- Cloudflare D1
- JavaScript
